
# Food Delivery System

## Overview
The Food Delivery System is a web-based application that allows users to order food from their favorite restaurants, track their orders, and enjoy timely deliveries. The platform bridges the gap between restaurants and customers, ensuring a seamless and satisfying experience.

---

## Features

### User Features

- **Search and Filter**: Search for dishes, restaurants, or cuisines, and apply filters like ratings or price range.


### Restaurant Features
- **Manage Menu**: Add, update, or remove dishes.
 - **add cart** : item can be added to cart.

### technology stack
- **HTML5, CSS3, JavaScript**: Core web technologies.
- **React.js**: Component-based UI development.
